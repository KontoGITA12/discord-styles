DISCORD STYLES, Discord z motywami

Style (menu "Styl" u góry): Discord, Niebieski, Nitro, MONO, Czerwony, Zielony, Sakura, Zmierzch.
Skrót Ctrl+Shift+T przełącza na następny. "Własny plik CSS..." pozwala wczytać swój motyw.

JAK ZBUDOWAĆ (GitHub):
1. Nowe repozytorium -> Add file -> Upload files -> wrzuć CAŁĄ zawartość tego folderu (z folderem .github).
2. Zakładka Actions -> poczekaj na zielony Build -> w Artifacts pobierz DiscordStyles -> w środku DiscordStyles.exe.
Lokalnie: npm install, npm start.

UWAGA: to okno z oficjalnym discord.com/app, tylko z nałożonym CSS. Zaloguj się normalnie.
Nazwy zmiennych CSS Discorda czasem się zmieniają, więc jeśli jakiś kolor nie działa, trzeba poprawić themes.js.
